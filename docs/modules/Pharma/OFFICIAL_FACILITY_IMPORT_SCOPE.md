# Official Facility Import — Scope Lock

In scope for phase 1:

- XLSX and CSV only;
- official facility staging/preview/audit;
- deterministic matching;
- explicit manual conflict resolution;
- checkbox selected-only import to Partner;
- Partner source provenance and canonical province support;
- bounded admin pagination and history.

Out of scope:

- PDF import;
- scraping;
- captcha bypass;
- private/session API synchronization;
- background auto-sync;
- fuzzy/AI facility matching;
- automatic likely/conflict merge;
- implicit whole-province import;
- source-specific IDs on Partner;
- automatic overwrite of manually maintained Partner identity/contact data.
