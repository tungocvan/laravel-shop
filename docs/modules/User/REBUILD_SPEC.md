# User Rebuild Spec

## Scope

Rebuild `User` as a legacy compatibility module, not as a new canonical user domain. Preserve the existing `/admin/user` staff CRUD screens while moving risky behavior behind a service layer and explicit permissions.

Do not migrate ownership away from `App\Models\User` in this slice. The canonical replacement remains `Identity`, as documented in `docs/modules/Identity/REBUILD_SPEC.md`.

## Compatibility Constraints

- Keep route names: `admin.user.index`, `admin.user.create`, `admin.user.edit`.
- Keep Livewire aliases generated by the module provider: `user.user-table`, `user.user-form`.
- Keep views under `User::pages.staff.*` and `User::livewire.*`.
- Replace legacy JSON import/export with shared Excel import/export.
- Keep non-Super Admin users from viewing or assigning `Super Admin`.
- Do not delete or disable `User` routes until `Identity` parity tests pass.

## Architecture

Route -> Controller -> Page Blade -> Livewire -> `UserService` -> `App\Models\User` / Spatie Role -> Database

Controllers only return views. Livewire owns UI state and permission checks. `UserService` owns staff queries, persistence, role synchronization, and deletion. `Modules\User\Services\ImportExport` owns Excel import/export.

## Authorization

- Routes require `auth:admin`.
- Index/export require `view_user`.
- Create/import require `create_user`.
- Edit/save existing users require `edit_user`.
- Delete single and bulk delete require `delete_user`.
- Excel import requires `import_user`.
- Excel export and template download require `export_user`/`import_user` respectively.
- Livewire methods repeat the relevant permission checks.

## Import/Export

- UI uses `shared.import-export.panel` on the staff index page.
- Service: `Modules\User\Services\ImportExport`.
- Format: `.xlsx` or `.csv` through FastExcel.
- Mapping mode: header/field name.
- Required headers: `name`, `email`.
- Optional import headers: `phone`, `password`, `is_active`, `roles`.
- If `roles` is empty or null, import defaults to `user`.
- Export-only header: `created_at`.
- Unique key: `email`.
- Default mode: `update_or_create`.
- `replace` is rejected for this module to avoid destructive user-account replacement.
- Roles are comma/semicolon/pipe separated in Excel, for example `Staff, Manager`.
- Import creates missing roles on the `admin` guard before syncing them to the user.
- Non-Super Admin actors cannot import/gán `Super Admin` and cannot update existing Super Admin accounts.

## Rebuild Decisions

- Cap pagination to 100 rows.
- Validate route IDs as numeric.
- Validate form data with Laravel rules.
- Create missing imported roles on the `admin` guard.
- Log import system failures without exposing raw exceptions to the UI.

## Future Work

- Move staff import/export to `Modules/Shared/Services/ImportExport` after the Excel/workbook contract is confirmed.
- Add Livewire authorization tests once the test suite has admin-user and permission factories.
- Disable or remove `User` after `Identity` has route, policy, data, and parity coverage.
